# 🔐 React Authentication App

A modern Authentication System built using React and Tailwind CSS.  
This project includes Signup, Login, Dashboard, and Logout functionality using LocalStorage for authentication.

---

## 🚀 Live Repository

GitHub Link:  
https://github.com/msoyabcode/react-authentication-app.git

---

## 🚀 Features

- User Signup
- User Login
- Dashboard Page
- Logout Functionality
- LocalStorage-based Authentication
- Responsive UI using Tailwind CSS
- Modern UI with React Icons

---

## 🛠️ Tech Stack

- React (Functional Components + Hooks)
- Tailwind CSS

- LocalStorage
- React Icons

## 🧠 How It Works

1. User registers using the Signup form.
2. User data is stored in LocalStorage.
3. User logs in using registered credentials.
4. After successful login, Dashboard is displayed.
5. Logout clears the current user session.

## 💻 Installation & Setup

Clone the repository:

git clone https://github.com/msoyabcode/react-authentication-app.git

Go to the project folder:

cd react-authentication-app

Install dependencies:

npm install

Run the project:

npm run dev
